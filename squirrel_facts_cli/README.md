# Squirrel Facts CLI — модульное приложение на Dart

Консольная система для ведения базы белок, орехов, предпочтений и фактов.

## Предметная область

- **Белки** (имя, окрас)
- **Орехи** (тип, количество на складе)
- **Предпочтения** (многие ко многим: белка → орех)
- **Факты о белках** (заголовок, описание, привязка к пользователю)
- **Пользователи** (регистрация, роль)

## Структура папок
lib/
squirrel.dart # публичный экспорт
src/
domain/
models/ # сущности с toMap/fromMap
validators/ # чистые функции валидации
data/
database.dart # SQLite и создание таблиц
repositories/ # CRUD-классы для каждой сущности
cli/
menu.dart # цикл меню, вызов репозиториев
input_helper.dart # повторный ввод с валидацией
bin/
main.dart # запуск
test/
squirrel_test.dart # тест CRUD для белок

## Что вынесено в каждый слой

- **domain** – только модели данных и правила валидации. Никакого SQL или ввода/вывода.
- **data** – работа с SQLite (таблицы, запросы). Импортирует domain, но не cli.
- **cli** – взаимодействие с пользователем, меню, ввод/вывод. Импортирует domain и data.
- **bin** – создание базы, запуск меню, закрытие ресурсов.

Такая модульность позволяет легко заменить БД (например, на JSON) или интерфейс (на веб).

## Валидация

1. **Обязательное текстовое поле** – имя, тип ореха, заголовок факта и т.д. (не пустая строка после trim).
2. **Числовое поле > 0** – поле `stock` (запас орехов) в сущности `Nut`.

Все валидации реализованы в `domain/validators/validators.dart` и используются в `input_helper.dart`.
